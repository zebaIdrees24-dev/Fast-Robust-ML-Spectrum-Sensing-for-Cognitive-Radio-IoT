# Fast-Robust-ML-Spectrum-Sensing-for-Cognitive-Radio-IoT
ML-based CR-IoT spectrum sensing using complex I/Q signals, Lanczos/PCA, MME, Ledoit-Wolf covariance, Random Forest, and HistGradientBoosting for low-SNR spectrum-occupancy detection. Built with Python, NumPy, SciPy, pandas, scikit-learn, Jupyter, Docker, and GitHub Actions.
